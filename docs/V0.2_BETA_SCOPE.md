# Smart Ventilation 0.2.0 beta scope

## Included in this beta foundation

- Arbitrary room records with independent temperature, humidity and optional CO2 sensors.
- Basic room geometry: floor area, ceiling height and derived volume.
- Window metadata: window area, orientation, type, opening mode and shading.
- Shared outdoor temperature/humidity and a Home Assistant current-weather entity.
- Numeric sensor validation, freshness checks, unit metadata and temperature conversion.
- Absolute humidity and dew-point calculations.
- Explainable room-level recommendations with missing-data handling and confidence labels.
- Home Assistant recommendation, duration, dew-point and humidity entities.
- A binary sensor for ventilation-needed status.
- Safety and limitations documentation; no actuator command is exposed.

## Not included / not yet safe to claim

- Weather forecast ingestion or provider selection (Open-Meteo, Ecowitt and other providers).
- Solar position/irradiance, pollen and outdoor air-quality forecast evaluation.
- Physically calibrated ventilation rates or guaranteed window-open durations.
- Window actuator integrations, confirmation UI, position verification or automatic closing.
- Dynamic creation/removal of entities after room changes without a config-entry reload.
- Full Home Assistant integration tests and release validation on supported HA versions.

## Beta acceptance checklist

- [ ] Run the GitHub Actions workflow successfully.
- [ ] Install on a clean Home Assistant test instance.
- [ ] Test config flow, options flow, adding/removing rooms and reload behavior.
- [ ] Verify sensors with missing, stale, unavailable and non-numeric states.
- [ ] Compare psychrometric calculations against reference values.
- [ ] Test recommendation behavior across humid/cold/hot/rainy cases.
- [ ] Review translated UI and HACS installation metadata.
